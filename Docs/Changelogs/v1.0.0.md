# ประวัติการเปลี่ยนแปลงระบบเวอร์ชัน 1.0.0 (HotelPOS TH Release History)

> **การควบคุมเวอร์ชัน**: ยึดตามกฎ `v1.0.0` ตลอดการพัฒนา ห้ามอัปเกรดเลขเวอร์ชัน

## ประวัติการปรับปรุงล่าสุด (Build Updates - Session Progress Log)

### 1. การ Rebrand เต็มรูปแบบเป็น PSoft Rest & Rent Manager
- **Assembly Names & Binaries:** กำหนดให้เอาต์พุตแอปพลิเคชันหลักคือกำลังคอมไพล์เป็น `PSoftRestRentManager.exe` และเครื่องมือ KeyGen คีย์ลิขสิทธิ์คอมไพล์ออกเป็น `PSoftRestRentGenerator.exe`
- **Data & Configuration Isolation:** ปรับเปลี่ยนที่อยู่จัดเก็บข้อมูลจริงของตัวโปรแกรม (ฐานข้อมูล SQLite และ Log ล่าสุด) ย้ายจากโฟลเดอร์ HotelPOS เดิมไปจัดเก็บแยกเป็นเอกเทศที่ `%AppData%\PSoftRestRentManager` และเปลี่ยนชื่อไฟล์ DB เป็น `restrent.db`
- **Registry & volume label:** ปรับเปลี่ยนคีย์ Registry ของโปรแกรมลิขสิทธิ์ทั้งหมดเป็น `Software\PSoftRestRentManager` และกำหนดให้ป้ายชื่อไดรฟ์ USB Dongle ลิขสิทธิ์แท้ที่ระบบใช้ตรวจหาเปลี่ยนเป็น `REST_RENT_KEY`
- **หน้าจอส่วนติดต่อผู้ใช้:** ปรับเปลี่ยนชื่อแอปพลิเคชัน หัวข้อ และข้อความต้อนรับของป้ายหัวไซด์บาร์นำทาง (Sidebar Brand Header) และ Default Settings ทั้งหมดให้แสดงแบรนด์ "PSoft R&R" / "PSoft Rest & Rent Manager"

### 2. การพัฒนาหน้าจอร้านค้ามินิบาร์และบริการเสริม (POS Shop Front Module - Phase 3)
- **สถาปัตยกรรมจัดเก็บข้อมูล (Dapper Repositories):** พัฒนาคลาส `ProductRepository` และ `SaleRepository` สำหรับดึงรายชื่อจัดกลุ่มสินค้า ทำธุรกรรมขาย (Transaction) บันทึกยอดเงินลงประวัติ และตัดสต็อกสินค้าในกรณีที่เปิดระบบควบคุมสต็อก
- **ระบบ Folio Integration:** ออกแบบให้ POS สามารถดึงรายชื่อห้องพักที่มีการ Check-in อยู่มาแสดงผล เพื่อให้เจ้าหน้าที่หน้าเคาน์เตอร์เลือกชาร์จเงินค่าสินค้าไปรวมเรียกเก็บใน Folio บิลรวมของห้องพักได้โดยตรง
- **ส่วนเชื่อมต่อผู้ใช้ (WinForms UI Views):** พัฒนา `POSControl` แยกโครงสร้าง 2 คอลัมน์ (Catalog เลือกสินค้า & Cart จัดการตะกร้า) พร้อมช่องทางชำระเงินในตัว มีการคำนวณเงินทอนอัตโนมัติ และเชื่อมเครื่องพิมพ์พิมพ์สลิปความร้อน (58mm/80mm) ทันทีหลังปิดบิล
- **การจัดการสินค้าและสต็อกในตัว (Inventory Management Dialog):** พัฒนาระบบ Inline Panel ให้ผู้ใช้งานจัดการเพิ่ม ลบ หรือแก้ไขรายชื่อสินค้า ประเภทสินค้า ราคาทุน ราคาขาย และใส่จำนวนสต็อกได้ทันทีจากเมนูขายหน้าร้าน

### 3. ระบบออกบิลรวมรายห้องประจำเดือน (ค่าน้ำ-ค่าไฟ-ค่าเช่า-ค่าขยะ-จิปาถะ) & ดูประวัติย้อนหลัง (`UtilityBillService`, `UtilityBillHistoryForm`)
- **บิลรวมใบเดียวรายห้อง (Combined Monthly Invoice):** สรุปรายการค่าห้องพัก + มิเตอร์ไฟ (เลขเดิม -> เลขใหม่ -> จำนวนหน่วย -> บาท) + มิเตอร์น้ำ (แบบมิเตอร์ หรือแบบเหมาจ่ายตามจำนวนคน) + ค่าขยะ + ค่าบริการส่วนกลาง + ค่าบริการจิปาถะ อยู่ในบิลใบเดียวสำหรับแต่ละห้อง
- **ดูประวัติย้อนหลังตลอดไป:** ปรับปรุงโครงสร้างฐานข้อมูล SQLite (`utility_bills`, `meter_readings`) ให้รองรับการบันทึกประวัติถาวร สามารถเรียกดูบิลย้อนหลังได้ทุกเดือน ทุกปี เลือกดูแยกตามห้อง หรือค้นหาตามเบอร์โทร/ชื่อผู้เช่า/เลขบิล
- **การยืนยัน Admin ID ก่อนเปลี่ยนราคาค่าน้ำ-ค่าไฟ:** ตั้งค่าอัตราค่าน้ำ/ค่าไฟต่อหน่วยได้อย่างปลอดภัย โดยระบบจะถามยืนยันรหัส Admin ID ซ้ำก่อนบันทึกทุกครั้ง

### 2. ระบบพิมพ์ใบเสร็จ/ใบแจ้งหนี้ A4 สมบูรณ์แบบ (พร้อมช่องข้อตกลงหน้าล็อบบี้) (`ReceiptInvoicePrinter`, `UtilityInvoicePrinter`, `CheckOutForm`, `BookingListControl`)
- **จัดวาง Layout A4 สมส่วน & ไร้รอยทับซ้อน:** ปรับปรุงความกว้างกล่องยอดรวมสุทธิเป็น 360 และขยับข้อความหลีกเลี่ยงการทับซ้อนกับตัวเลขเงินรวมสุทธิอย่างถาวร พร้อมขยายขนาดฟอนต์และปรับระยะช่องไฟแนวตั้ง (Vertical Spacing) เพื่อจัดหน้าบิล A4 ให้สมบูรณ์สวยงาม ไม่เหลือขอบกระดาษว่างด้านล่าง
- **ช่องข้อตกลงหน้าล็อบบี้ (Lobby Terms & Conditions):** เพิ่มกรอบแสดงข้อตกลงและเงื่อนไขหน้าล็อบบี้/เคาน์เตอร์ ที่ตั้งค่าไว้จากหน้าตั้งค่าระบบลงในเอกสาร A4 โดยอัตโนมัติ
- **พร้อมเพย์ QR Code & ช่องเซ็นชื่อ:** รองรับการแสดงผล PromptPay QR Code อัตโนมัติ พร้อมช่องลงลายมือชื่อผู้เข้าพักและเจ้าหน้าที่สมดุลสวยงาม
- **รวมยอดค่าน้ำ/ค่าไฟ/บริการลงในบิลค่าเช่าหลักใบเดียว:** รองรับการดึงข้อมูลและรายละเอียดการใช้น้ำ มิเตอร์ไฟ และค่าธรรมเนียมอื่น ๆ ของรอบบิลเดือนนั้น ๆ มารวมแจกแจงลงในตารางสรุปของบิลหลักโดยตรง สะดวก รวดเร็ว ประหยัดกระดาษ (และยังคงความสามารถพิมพ์แยกประเภทได้อยู่ตามที่ผู้ใช้ต้องการ)

### 3. ระบบค้นหาข้อมูลแบบ Real-Time (Instant Typing Search)
- **กรองผลลัพธ์ทันทีที่พิมพ์:** เพียงพิมพ์เบอร์โทรศัพท์ (เช่น `089`), ชื่อผู้เข้าพัก, เลขห้อง, รหัสการจอง หรือเลขบิล ตารางแสดงผลจะทำการกรองข้อมูลทันทีทุกตัวอักษรที่พิมพ์ โดยไม่ต้องกดปุ่มค้นหา
- **ครอบคลุมทุกหน้าตาราง:** หน้าลูกค้า (`CustomerManagementControl`), หน้ารายการจอง (`BookingListControl`), หน้าบันทึกมิเตอร์ค่าน้ำค่าไฟ (`MeterReadingControl`), หน้าประวัติบิลย้อนหลัง (`UtilityBillHistoryForm`), หน้าจัดการห้องพัก & ประเภทห้อง (`RoomManagementControl`)

### 4. ระบบ Logger & Error Popup เจาะลึกทุกรายละเอียดทุกซอกทุกมุม (`DetailedErrorDialog`, `Program.cs`)
- **เก็บรายละเอียดลึกซึ้งทุกมุม:** บันทึก Timestamp ละเอียดระดับมิลลิวินาที, Exception Cascade (Inner Exceptions), Stack Trace พร้อมเลขบรรทัด, System Diagnostics (Memory, OS, Process ID, Managed Thread ID) และ User Context
- **ดักจับครบทุกระดับ:** ดัก Exception ทั้งจาก UI Thread (`Application.ThreadException`), AppDomain (`AppDomain.CurrentDomain.UnhandledException`), และ Async Task (`TaskScheduler.UnobservedTaskException`)
- **ปุ่มอำนวยความสะดวกใน Error Dialog:** เพิ่มปุ่ม `[ 📋 คัดลอกรายละเอียดข้อผิดพลาด ]` ลง Clipboard และปุ่ม `[ 📁 เปิดโฟลเดอร์ Log ]` เพื่อเข้าถึงไฟล์ Log ใน Windows Explorer โดยตรง

### 5. ระบบ ToolTip ขนาดใหญ่อ่านง่าย ไม่กินเฟรม ตกขอบไม่หาย 100% (`AppToolTip`)
- **ตัวหนังสือใหญ่อ่านง่ายสบายตา:** ใช้ฟอนต์ **Segoe UI 11pt - 11.5pt Bold** สไตล์ Modern Dark Slate คมชัดบนทุกพื้นหลัง
- **ระบบ Safe Screen Boundary Protection:** คำนวณขอบหน้าจอ (`WorkingArea`) อัตโนมัติ ขยับหลบไม่ให้ ToolTip กินเฟรมหรือตกขอบจอเด็ดขาด

### 6. ระบบแบ่งสีประเภทราคาชัดเจน (Daily, Hourly, Monthly) & ผังห้องพักพรีเมียม (`RoomGridControl`, `RoomManagementControl`)
- **แบ่งสีประเภทราคาเด่นชัด:**
  - 🌞 **รายวัน (Daily Rate):** สีเขียวมรกต (`Emerald Tag: #059669`)
  - ⏱️ **รายชั่วโมง (Hourly Rate):** สีส้มแอมเบอร์ (`Amber Tag: #D97706`)
  - 📅 **รายเดือน (Monthly Rate):** สีม่วงพรีเมียม (`Purple Tag: #7C3AED`)
- **ผังห้องพัก Visual Tiles รูปแบบใหม่:** การ์ดห้องพักแสดงเลขห้องขนาดใหญ่ 12pt Bold, ป้ายประเภทราคาพร้อมราคาต่อหน่วย, รายชื่อผู้พัก, เวลาครบกำหนดเช็คเอาท์, และปุ่มแอคชัน 1-Click บนการ์ดห้องพักครบถ้วน

### 7. ปรับปรุง UI/UX หน้าตั้งค่าระบบ (`SystemSettingsControl`) & ลบอิโมจิ
- **ลบอิโมจิภายใน Front-End:** ตัดสัญลักษณ์อิโมจิออกทั้งหมดตามข้อกำหนด ให้หน้าจอสะอาดตา สไตล์ SaaS Dashboard พรีเมียม
- **ปรับปรุง Layout หน้าตั้งค่าระบบ:** ขยายความสูงกรอบและจัดตำแหน่งควบคุมในหน้าตั้งค่าระบบ ไม่ทับซ้อน ไม่ถูกกินเฟรม พร้อมสเปเซอร์ด้านล่าง

### 8. การทดสอบและการคลีนอัพฐานข้อมูล (Clean Database & 100% Pass Tests)
- **เคลียร์ข้อมูลทดสอบเก่า:** ทำการคลีนอัพข้อมูลทดสอบเก่าค้างทั้งหมด คงไว้เฉพาะโครงสร้างห้องพักมาตรฐาน
- **ผ่าน Unit Tests ทั้งหมด:** ผ่านการทดสอบระดับยูนิต 34/34 เคส (100% Pass Rate)

### 9. ระบบจัดการความปลอดภัยลิขสิทธิ์ และล้างฐานข้อมูลขึ้นใช้งานจริง (Set Zero & Continuous Dongle Check)
- **ระบบล้างธุรกรรมระบบทั้งหมดเป็น 0 (Database Set Zero):** ปุ่มควบคุมในหน้าตั้งค่าระบบเพื่อล้างประวัติธุรกรรม การเงิน การจอง ลูกค้า และบิลทั้งหมดแบบ Auto-increment sequence reset โดยคงห้องพักประเภทและสิทธิ์การลงทะเบียนลิขสิทธิ์ไว้ พร้อมด่านถามรหัสผ่าน Admin ยืนยัน 2 ชั้น ป้องกันอุบัติเหตุการลบข้อมูล
- **การกำหนดรหัสผ่าน Admin เมื่อลงทะเบียนครั้งแรก:** นำหน้าจอ `AdminPasswordSetupForm` มาบังคับให้ผู้ใช้งานตั้งรหัสผ่าน Admin สำหรับการเปิดสิทธิ์ USB Dongle แท้ครั้งแรกเพื่อความปลอดภัย
- **ระบบติดตามอุปกรณ์ Dongle และโหมดผ่อนผัน 5 นาที (Grace Period):** ตรวจเช็ค USB Dongle ทุก 15 วินาทีเบื้องหลัง หากตรวจไม่พบจะเริ่มนับเวลาผ่อนผัน 5 นาที ให้ผู้ใช้ทำงานค้างอยู่เสร็จและเซฟงานแบบไม่ล็อคหน้าจอทันที หากเสียบกลับจะคืนสถานะปกติอัตโนมัติ
- **คลีนอัปอิโมจิในหน้าหลัก (Emoji-Free UI Front End):** นำสัญลักษณ์อิโมจิทั้งหมดออกจากปุ่ม ตาราง และกล่องข้อความหน้าใช้งานหลัก เพื่อส่งมอบภาพลักษณ์ Dashboard ซอฟต์แวร์ระดับพรีเมียม
- **ผ่านการรันระบบทดสอบอัตโนมัติ:** การรันทดสอบระบบ License และความปลอดภัยครอบคลุม 35/35 เคสสำเร็จลุล่วง

### 10. ระบบทางลัดมินิบาร์ ผังห้องพักคัดกรองรายวัน ค้นหาประวัติ POS ลึกซึ้ง และพิมพ์ออดิต A4 (Build Updates - 2026-07-28)
- **ปุ่มยกเลิกบิลขายหน้าร้าน (POS Void Sale):** พัฒนาฟังก์ชัน `VoidSaleAsync` ทำงานแบบ Database Transaction เพื่อลบยอดขาย กู้คืนจำนวนสินค้าสต็อก และปรับยอดค้างชำระใน Folio ของห้องพักทันทีหากมีการชาร์จห้องไว้
- **แก้ไขบัคคัดกรองรายวัน:** ปรับปรุงเงื่อนไขเช็ค `DailyRate > 0` บนปุ่มตัวกรอง "รายวัน" ของ Room Grid และแสดงรายละเอียดประเภทราคาของผู้พัก (รายวัน / รายชั่วโมง / รายเดือน) ต่อท้ายชื่อผู้เข้าพักในวงเล็บเด่นชัด
- **ทางลัดสั่งมินิบาร์ด่วน:** เพิ่มเมนูคลิกขวา (Context Menu) "สั่งมินิบาร์ / สั่งสินค้า (POS)" สำหรับห้องพักที่มีผู้เข้าพักจริง โดยเมื่อกดคลิกจะสลับหน้าจอมาที่ POS พร้อมสั่งชาร์จเงินเข้า Folio ห้องพักนั้นทันที
- **ค้นหาประวัติ POS ตามชื่อหรือเลขห้อง:** ปรับปรุงการ Join ตารางฐานข้อมูลประวัติการขาย POS ให้สามารถดึงเลขห้องพักและชื่อลูกค้ามาค้นหาและจัดแสดงในตารางประวัติได้ ทำให้สามารถค้นหาย้อนหลังผ่านชื่อลูกค้าหรือเลขห้องพักได้โดยตรง
- **ส่งออกและพิมพ์รายงาน A4 (Audit Log Export):** พัฒนาความสามารถในการส่งออกประวัติออดิตระบบออกเป็นไฟล์ HTML ขนาด 210mm พอดีขอบกระดาษ A4 สวยงามเป็นระเบียบ และสามารถเปิดพิมพ์ผ่านเบราว์เซอร์ รวมถึงการส่งออกไฟล์ข้อมูล CSV เพื่อเปิดดูใน Microsoft Excel

### 11. ระบบแบ่งตารางข้อมูลเป็นหน้า ป้องกัน Excel เพี้ยน ประวัติลูกค้าลึกซึ้ง และการพิมพ์ Layout A4 (Build Updates - 2026-07-29)
- **ระบบแบ่งหน้าข้อมูลในตาราง (Grid Pagination System):** พัฒนาคลาสส่วนกลาง `GridPaginationPanel` ขึ้นมาควบคุมการสไลด์และโหลดข้อมูลของตารางที่มีข้อมูลประวัติปริมาณสูงในระบบ เพื่อป้องกันหน้าจอค้างหรือกระตุก (UI Lag) ในคอมพิวเตอร์ระดับกลางถึงล่าง ครอบคลุม: หน้าจัดการผู้เข้าพัก, หน้ารายการจอง, หน้าประวัติบิลขาย POS, หน้าประวัติค่าน้ำไฟ และล็อคบันทึกประวัติการใช้ระบบ (Audit Logs)
- **แก้ปัญหาตัวเลขสตริงเบอร์โทร/เลขบัตรใน Excel เพี้ยน (Scientific Notation & Zero Dropping):** ปรับปรุงตรรกะใน `ExportImportService` ให้ทำการครอบรหัสตัวเลขสตริงด้วยรูปแบบสูตร Excel (`"=""{value}"""`) เพื่อแก้ไขตัวเลขเบอร์โทรและเลขบัตรประชาชนโดน Excel ตัดเลขศูนย์ตัวแรกทิ้ง หรือเปลี่ยนเป็นรูปแบบเลขยกกำลัง (เช่น 1.1E+12)
- **ประวัติลูกค้าเชิงลึก (Customer Spend & Utility Deep-Dive):**
  - เพิ่มแท็บ **"⚡ ค่าน้ำ/ค่าไฟ"** ในรายละเอียดประวัติลูกค้าด้านขวา โดยจะค้นหาใบแจ้งหนี้ค่าน้ำไฟของห้องที่ลูกค้าพักตามวันเวลาที่ทับซ้อนกันมาแสดงโดยอัตโนมัติ
  - เพิ่มการดับเบิ้ลคลิกแถวตารางย้อนหลังของลูกค้าเพื่อเรียกดูตัวอย่างพิมพ์บิลจริง (Double-Click Preview) ได้ทันที: ประวัติพัก ดับเบิ้ลคลิกเพื่อดูสลิปบิลห้องพักย้อนหลัง A4, ประวัติขาย POS ดับเบิ้ลคลิกเพื่อดูสลิปพิมพ์ POS ย้อนหลัง, ประวัติค่าน้ำไฟ ดับเบิ้ลคลิกเพื่อดูตัวอย่างใบแจ้งหนี้ค่าน้ำค่าน้ำไฟ A4 ย้อนหลัง
- **แก้ไขงานพิมพ์ตัวหนังสือทับซ้อนและล้นกรอบ (GDI+ Print Layout Fixes):**
  - แก้ไขปัญหาหัวบิลและเลขที่บิลเบียดทับซ้อนกันใน A4 Layout โดยใช้ `StringFormat` จัดแนวขวา (Far Alignment) อิงขอบเขตกระดาษแทนระยะพิกัดดิบ
  - แก้ไขลายเซ็นล้นขอบช่องลงนาม โดยลดขนาดฟอนต์ของชื่อตำแหน่งเซ็นลงนามเป็น Tahoma 9.5F หนา ทำให้วางเรียงสวยงามเรียบร้อย ไม่ล้นเส้นกรอบและไม่ล้นแบ่งหน้า
- **ความเรียบร้อยของโค้ดและการทดสอบ:** แก้ไข Namespace `AuditLogEntry` และเพิ่ม `using HotelPOS.Common;` ในคอนโทรลจัดการผู้เข้าพัก เพื่อให้สามารถคอมไพล์โปรเจคได้สำเร็จราบรื่น พร้อมผ่านการทดสอบอัตโนมัติ 37/37 เคสอย่างสมบูรณ์
