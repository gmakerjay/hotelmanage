### 2. ยกระดับ UX การตั้งค่าห้องพัก และคอลัมน์ปุ่มแอคชันในตาราง (`RoomManagementControl`)
- เพิ่มคอลัมน์ปุ่ม **`✏️ แก้ไข`** และ **`🗑️ ลบ`** ลงใน DataGridView โดยตรงทุกแถว ทั้งตารางประเภทห้องพักและตารางเลขห้องพัก
- เพิ่มแถบสถานะโหมดแก้ไข (Mode Indicator Banner) พร้อมปุ่ม `[ ❌ ยกเลิกแก้ไข ]` ให้สลับโหมดป้อนข้อมูลได้อย่างชัดเจน
- ปรับปรุงการผูกประเภทห้องพักด้วย `RoomTypeComboItem` แสดงราคาห้องชัดเจน และแก้อาการเลือก/ลบห้องเพี้ยน

### 3. ปรับโฉมผังห้องพักเป็น Visual Tiles สไตล์ POS ร้านอาหาร (`RoomGridControl`)
- ออกแบบผังห้องพักสไตล์ Restaurant POS Floor Plan Tiles (230x175 px)
- ใส่แถบสีประจำสถานะ:
  - 🟢 **ว่าง** (Forest Green)
  - 🔴 **มีคนพัก** (Crimson Red)
  - 🟡 **รอทำความสะอาด** (Amber Yellow)
  - 🔵 **จองล่วงหน้า** (Royal Blue)
  - ⚙️ **ปิดซ่อม** (Slate Gray)
- ใส่ปุ่ม Quick Action บนการ์ดห้องพักสำหรับกด เช็คอิน / เช็คเอาท์ / ทำความสะอาดเสร็จ / เปิดใช้งาน ได้รวดเร็ว 1-Click
- เพิ่มแถบปุ่มกรองสถานะสไตล์ POS Filter Tabs

- ปรับโครงสร้างเมนูหลักใน [MainForm.cs](file:///c:/Users/admin/Documents/HotelPOS/src/HotelPOS.UI/MainForm.cs) เป็นแถบไซด์บาร์ด้านซ้ายโทนสีดำเข้ม `#14141E`
- ตัดอิโมจิออกทั้งหมดเพื่อความสะอาด ตาเป็นระเบียบ เรียบหรู สไตล์ SaaS Dashboard

### 6. ระบบออกใบเสร็จรับเงิน/ใบแจ้งหนี้พร้อมช่องเซ็นชื่อ (`ReceiptInvoicePrinter.cs`)
- สร้าง Engine การพิมพ์ใบเสร็จรองรับทั้งขนาดกระดาษ A4, Slip 80mm และ 58mm
- พิมพ์รายละเอียดผู้เข้าพัก, ทะเบียนรถยนต์, ตารางค่าห้องพัก, ค่าบริการเสริม, ส่วนลด, ยอดเงินสุทธิ
- เพิ่มช่องลงลายมือชื่อผู้เข้าพัก (`Guest Signature`) และเจ้าหน้าที่ (`Staff Signature`)
- รองรับการย่อ/ขยายรูปภาพโลโก้โรงแรม และรูป PromptPay QR Code อัตโนมัติ (Auto-Resize Keep Aspect Ratio)

### 7. ระบบตั้งค่า Backend ครบวงจร (`SystemSettingsControl.cs`)
- เพิ่มหน้าจอตั้งค่าข้อมูลโรงแรม, เลขผู้เสียภาษี, ข้อความหัวบิล/ท้ายบิล
- เลือกเครื่องพิมพ์ Windows, ขนาดกระดาษ, อัตราภาษี VAT %, และเงินมัดจำเริ่มต้น

### 8. สถาปัตยกรรม Logger & Audit Trail แบบจำแนกโฟลเดอร์ (`AppLogger.cs`)
- ปรับโครงสร้าง Serilog Logger เป็นแบบแยกหมวดหมู่โฟลเดอร์: `errors/`, `system/`, `database/`, `audit/`, `json/`
- ป้องกันไฟล์บวมและกระจุก ด้วยระบบหมุนเวียนไฟล์รายวัน (Daily Rolling)
- จำกัดขนาดไฟล์สูงสุดไม่เกิน **5 MB** ต่อไฟล์ และลบไฟล์เก่าเกิน **90 วัน** อัตโนมัติ
- จัดทำเอกสารคู่มือ [Docs/LOGGER_AND_AUDIT_GUIDE.md](file:///c:/Users/admin/Documents/HotelPOS/Docs/LOGGER_AND_AUDIT_GUIDE.md)
