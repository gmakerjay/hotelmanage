## ประวัติการปรับปรุงล่าสุด (Build Updates - Session Progress Log)

### 1. ระบบออกบิลรวมรายห้องประจำเดือน (ค่าน้ำ-ค่าไฟ-ค่าเช่า-ค่าขยะ-จิปาถะ) & ดูประวัติย้อนหลัง (`UtilityBillService`, `UtilityBillHistoryForm`)
- **บิลรวมใบเดียวรายห้อง (Combined Monthly Invoice):** สรุปรายการค่าห้องพัก + มิเตอร์ไฟ (เลขเดิม -> เลขใหม่ -> จำนวนหน่วย -> บาท) + มิเตอร์น้ำ (แบบมิเตอร์ หรือแบบเหมาจ่ายตามจำนวนคน) + ค่าขยะ + ค่าบริการส่วนกลาง + ค่าบริการจิปาถะ อยู่ในบิลใบเดียวสำหรับแต่ละห้อง
- **ดูประวัติย้อนหลังตลอดไป:** ปรับปรุงโครงสร้างฐานข้อมูล SQLite (`utility_bills`, `meter_readings`) ให้รองรับการบันทึกประวัติถาวร สามารถเรียกดูบิลย้อนหลังได้ทุกเดือน ทุกปี เลือกดูแยกตามห้อง หรือค้นหาตามเบอร์โทร/ชื่อผู้เช่า/เลขบิล
- **การยืนยัน Admin ID ก่อนเปลี่ยนราคาค่าน้ำ-ค่าไฟ:** ตั้งค่าอัตราค่าน้ำ/ค่าไฟต่อหน่วยได้อย่างปลอดภัย โดยระบบจะถามยืนยันรหัส Admin ID ซ้ำก่อนบันทึกทุกครั้ง

### 2. ระบบพิมพ์ใบเสร็จ/ใบแจ้งหนี้ A4 สมบูรณ์แบบ (พร้อมช่องข้อตกลงหน้าล็อบบี้) (`ReceiptInvoicePrinter`, `UtilityInvoicePrinter`)
- **จัดวาง Layout A4 สมส่วน:** ปรับแต่งการคำนวณตำแหน่งพิมพ์บนกระดาษ A4 ไม่ให้กระจุกตัวอยู่ด้านบน และไม่มีตัวหนังสือทับซ้อนกัน 100%
- **ช่องข้อตกลงหน้าล็อบบี้ (Lobby Terms & Conditions):** เพิ่มกรอบแสดงข้อตกลงและเงื่อนไขหน้าล็อบบี้/เคาน์เตอร์ ที่ตั้งค่าไว้จากหน้าตั้งค่าระบบลงในเอกสาร A4 โดยอัตโนมัติ
- **พร้อมเพย์ QR Code & ช่องเซ็นชื่อ:** รองรับการแสดงผล PromptPay QR Code อัตโนมัติ พร้อมช่องลงลายมือชื่อผู้เข้าพักและเจ้าหน้าที่สมดุลสวยงาม

### 3. ระบบค้นหาข้อมูลแบบ Real-Time (Instant Typing Search)
- **กรองผลลัพธ์ทันทีที่พิมพ์:** เพียงพิมพ์เบอร์โทรศัพท์ (เช่น `089`), ชื่อผู้เข้าพัก, เลขห้อง, รหัสการจอง หรือเลขบิล ตารางแสดงผลจะทำการกรองข้อมูลทันทีทุกตัวอักษรที่พิมพ์ โดยไม่ต้องกดปุ่มค้นหา
- **ครอบคลุมทุกหน้าตาราง:** หน้าลูกค้า (`CustomerManagementControl`), หน้ารายการจอง (`BookingListControl`), หน้าบันทึกมิเตอร์ค่าน้ำค่าไฟ (`MeterReadingControl`), หน้าประวัติบิลย้อนหลัง (`UtilityBillHistoryForm`), หน้าจัดการห้องพัก & ประเภทห้อง (`RoomManagementControl`)

### 4. ระบบ Logger & Error Popup เจาะลึกทุกรายละเอียดทุกซอกทุกมุม (`DetailedErrorDialog`, `Program.cs`)
- **เก็บรายละเอียดลึกซึ้งทุกมุม:** บันทึก Timestamp ละเอียดระดับมิลลิวินาที, Exception Cascade (Inner Exceptions), Stack Trace พร้อมเลขบรรทัด, System Diagnostics (Memory, OS, Process ID, Managed Thread ID) และ User Context
- **ดักจับครบทุกระดับ:** ดัก Exception ทั้งจาก UI Thread (`Application.ThreadException`), AppDomain (`AppDomain.CurrentDomain.UnhandledException`), และ Async Task (`TaskScheduler.UnobservedTaskException`)
- **ปุ่มอำนวยความสะดวกใน Error Dialog:** เพิ่มปุ่ม `[ 📋 คัดลอกรายละเอียดข้อผิดพลาด ]` ลง Clipboard และปุ่ม `[ 📁 เปิดโฟลเดอร์ Log ]` เพื่อเข้าถึงไฟล์ Log ใน Windows Explorer โดยตรง

### 5. ระบบ ToolTip ขนาดใหญ่อ่านง่าย ไม่กินเฟรม ตกขอบไม่หาย 100% (`AppToolTip`)
- **ตัวหนังสือใหญ่อ่านง่ายสบายตา:** ใช้ฟอนต์ **Segoe UI 11pt - 11.5pt Bold** สไตล์ Modern Dark Slate คมชัดบนทุกพื้นหลัง
- **ระบบ Safe Screen Boundary Protection:** คำนวณขอบหน้าจอ (`WorkingArea`) อัตโนมัติ ขยับหลบไม่ให้ ToolTip กินเฟรมหรือตกขอบจอเด็ดขาด

### 6. ระบบแบ่งสีประเภทราคาชัดเจน (Daily, Hourly, Monthly) & ผังห้องพักพรีเมียม (`RoomGridControl`, `RoomManagementControl`)
- **แบ่งสีประเภทราคาเด่นชัด:**
  - 🌞 **รายวัน (Daily Rate):** สีเขียวมรกต (`Emerald Tag: #059669`)
  - ⏱️ **รายชั่วโมง (Hourly Rate):** สีส้มแอมเบอร์ (`Amber Tag: #D97706`)
  - 📅 **รายเดือน (Monthly Rate):** สีม่วงพรีเมียม (`Purple Tag: #7C3AED`)
- **ผังห้องพัก Visual Tiles รูปแบบใหม่:** การ์ดห้องพักแสดงเลขห้องขนาดใหญ่ 12pt Bold, ป้ายประเภทราคาพร้อมราคาต่อหน่วย, รายชื่อผู้พัก, เวลาครบกำหนดเช็คเอาท์, และปุ่มแอคชัน 1-Click บนการ์ดห้องพักครบถ้วน

### 7. ปรับปรุง UI/UX หน้าตั้งค่าระบบ (`SystemSettingsControl`) & ลบอิโมจิ
- **ลบอิโมจิภายใน Front-End:** ตัดสัญลักษณ์อิโมจิออกทั้งหมดตามข้อกำหนด ให้หน้าจอสะอาดตา สไตล์ SaaS Dashboard พรีเมียม
- **ปรับปรุง Layout หน้าตั้งค่าระบบ:** ขยายความสูงกรอบและจัดตำแหน่งควบคุมในหน้าตั้งค่าระบบ ไม่ทับซ้อน ไม่ถูกกินเฟรม พร้อมสเปเซอร์ด้านล่าง

### 8. การทดสอบและการคลีนอัพฐานข้อมูล (Clean Database & 100% Pass Tests)
- **เคลียร์ข้อมูลทดสอบเก่า:** ทำการคลีนอัพข้อมูลทดสอบเก่าค้างทั้งหมด คงไว้เฉพาะโครงสร้างห้องพักมาตรฐาน
- **ผ่าน Unit Tests ทั้งหมด:** ผ่านการทดสอบระดับยูนิต 34/34 เคส (100% Pass Rate)
