## 🔍 รายละเอียดความคืบหน้าแต่ละโมดูล (Completed Features)

### 1. ระบบออกบิลรวมรายห้องประจำเดือน (Combined Monthly Utility Invoice)
- [x] ออกบิลรวมใบเดียวรายห้อง (ค่าเช่า + มิเตอร์ไฟ + มิเตอร์น้ำ + ค่าบริการส่วนกลาง + ค่าขยะ + ค่าจิปาถะ)
- [x] ดูประวัติบิลย้อนหลังได้ตลอดทุกเดือน ทุกปี Filter ตามห้อง หรือค้นหาตามเบอร์โทร/ชื่อผู้เช่า/เลขบิล
- [x] ถามยืนยัน Admin ID ก่อนเปลี่ยนราคาค่าน้ำ/ค่าไฟต่อหน่วย

### 2. ระบบเอกสารใบเสร็จ/ใบแจ้งหนี้ A4 รูปแบบใหม่ (Receipt & Utility Invoice Engine)
- [x] ออกแบบ Layout A4 ใหม่ สมส่วน 100% ไม่กระจุกตัวด้านบน ตัวหนังสือไม่ทับซ้อนกัน
- [x] เพิ่มช่องข้อตกลงและเงื่อนไขหน้าล็อบบี้/เคาน์เตอร์ (Lobby Terms & Conditions) อัตโนมัติ
- [x] พิมพ์ใบเสร็จเช็คเอาท์ และใบแจ้งหนี้รวมประจำเดือน A4 พร้อม PromptPay QR Code และช่องเซ็นชื่อผู้เข้าพัก/เจ้าหน้าที่
- [x] ป้องกันตัวหนังสือกับยอดเงินรวมทับซ้อนกันอย่างถาวรในกล่องยอดเงินสุทธิ
- [x] ปรับขยายขนาดฟอนต์และระยะช่องไฟแนวตั้ง (Vertical Spacing) เพื่อจัดหน้าบิล A4 ให้สมส่วนสวยงามพรีเมียม ไม่เหลือขอบกระดาษว่างด้านล่างมากเกินไป
- [x] เพิ่มความสามารถในการควบรวมค่าน้ำ ค่าไฟ และค่าบริการอื่น ๆ มารายงานในบิลใบเสร็จห้องพักใบเดียวกันตอน Checkout หรือออกเอกสารหลักได้ (และคงสิทธิ์พิมพ์เอกสารแยกประเภทได้ตามใจชอบ)

### 3. ระบบค้นหาข้อมูลแบบ Real-Time (Instant Typing Search)
- [x] พิมพ์เบอร์โทรศัพท์ (เช่น `089`), ชื่อผู้เข้าพัก, เลขห้อง, รหัสจอง หรือเลขบิล แล้วตารางกรองข้อมูลทันทีทุกตัวอักษรที่พิมพ์
- [x] รองรับในตารางลูกค้า, รายการจอง, บันทึกมิเตอร์ค่าน้ำค่าไฟ, ประวัติบิลย้อนหลัง, และหน้าจัดการห้องพัก

### 4. ระบบ Logger & Error Popup เจาะลึกทุกซอกทุกมุม (`DetailedErrorDialog`)
- [x] บันทึกและแสดง Exception Cascade, Stack Trace พร้อมเลขบรรทัด, System Diagnostics (Memory, OS, Thread ID) และ User Context
- [x] ดักจับทั้ง UI Thread, AppDomain Unhandled Exception, และ Async Task Exception
- [x] Error Dialog สีแดงพร้อมปุ่ม `[ คัดลอกรายละเอียดข้อผิดพลาด ]` และ `[ เปิดโฟลเดอร์ Log ]`

### 5. ระบบ ToolTip ขนาดใหญ่อ่านง่าย ไม่กินเฟรม ตกขอบไม่หาย (`AppToolTip`)
- [x] ฟอนต์ใหญ่คมชัด **Segoe UI 11pt - 11.5pt Bold** สไตล์ Modern Dark Slate
- [x] คำนวณขอบหน้าจอ (`WorkingArea`) อัตโนมัติ ขยับหลบไม่ให้ ToolTip กินเฟรมหรือตกขอบจอเด็ดขาด

### 6. ระบบแบ่งสีประเภทราคาชัดเจน & ผังห้องพักพรีเมียม (`RoomGridControl`)
- [x] แบ่งสีประเภทราคาเด่นชัด:
  - 🌞 **รายวัน (Daily Rate):** สีเขียวมรกต (`Emerald Tag: #059669`)
  - ⏱️ **รายชั่วโมง (Hourly Rate):** สีส้มแอมเบอร์ (`Amber Tag: #D97706`)
  - 📅 **รายเดือน (Monthly Rate):** สีม่วงพรีเมียม (`Purple Tag: #7C3AED`)
- [x] ผังห้องพัก Visual Tiles แสดงเลขห้อง 12pt Bold, ป้ายประเภทราคาพร้อมราคาต่อหน่วย, รายชื่อผู้พัก, เวลาเช็คเอาท์, และปุ่มแอคชัน 1-Click

### 7. การทดสอบและความเสถียร DB (100% Pass Tests)
- [x] คลีนอัพข้อมูลทดสอบเก่าค้างเรียบร้อย
- [x] Unit Tests / Integration Tests ผ่านทั้งหมด 37/37 เคส (100% Pass)

### 8. ระบบจัดการความปลอดภัยลิขสิทธิ์ และล้างฐานข้อมูลขึ้นใช้งานจริง (Set Zero & Continuous Dongle Check)
- [x] ปุ่มล้างระบบเป็น 0 (Set Zero) ที่แท้จริง ดึงประวัติธุรกรรม ลูกค้า โฟลิโอ บิล ออกทั้งหมดแบบ Auto-increment reset แต่คงโครงสร้างห้องพักและสิทธิ์ไว้
- [x] ระบบถามรหัสผ่าน Admin ซ้ำ 2 ชั้น เพื่อยืนยันความปลอดภัยในการสั่ง Set Zero
- [x] บังคับลงทะเบียนรหัสผ่าน Admin สำหรับการเปิดสิทธิ์ USB Dongle แท้ครั้งแรกผ่านหน้าจอ `AdminPasswordSetupForm` ป้องกันการขโมยคีย์เริ่มต้น
- [x] ระบบติดตามและตรวจจับการเชื่อมต่อ USB Dongle ตลอดเวลาทุก 15 วินาที พร้อมระบบผ่อนผัน 5 นาที (Grace Period) แจ้งเตือนแบบไม่ขัดจังหวะการบันทึกข้อมูลของผู้ใช้
- [x] นำไอคอนอีโมจิทั้งหมดออกจากส่วนหน้าจอหลักที่ผู้ใช้ทั่วไปใช้งาน (Front End UI) เพื่อดีไซน์ที่เป็นมืออาชีพและพรีเมียมที่สุด

### 9. ระบบทางลัดมินิบาร์ ผังห้องพักคัดกรองรายวัน ค้นหาประวัติ POS ลึกซึ้ง และพิมพ์ออดิต A4
- [x] แก้ไขบัคปุ่มตัวกรอง "รายวัน" ของ Room Grid ให้เช็คค่า `DailyRate > 0`
- [x] แสดงรายละเอียดรูปแบบราคา `(รายวัน)` `(รายชั่วโมง)` หรือ `(รายเดือน)` บนการ์ดห้องพักที่มีคนเข้าพักหรือจองล่วงหน้า
- [x] เพิ่มปุ่มคลิกขวา "สั่งมินิบาร์ / สั่งสินค้า (POS)" สำหรับห้องพักที่มีผู้เข้าพักจริง ย้ายหน้าเข้าสู่หน้า POS ชาร์จเงินอัตโนมัติ
- [x] ปรับปรุง SQL การดึงประวัติ POS History ให้ค้นหาย้อนหลังผ่านชื่อลูกค้าหรือเลขห้องพักได้
- [x] เพิ่มปุ่ม "ส่งออก/พิมพ์ A4" ในหน้าประวัติการทำงาน AuditLog
- [x] ส่งออกไฟล์ HTML (A4 Print Layout) ขนาด 210mm พอดีขอบกระดาษสวยงามสำหรับสั่งพิมพ์ออกเครื่องพิมพ์ได้ทันที
- [x] ส่งออกไฟล์ CSV สำหรับนำไปคำนวณและวิเคราะห์สถิติต่อใน Microsoft Excel
