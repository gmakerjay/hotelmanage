## 1. ภาพรวมและความปลอดภัย (Overview & Security)

โปรแกรม **PSoftRestRentGenerator.exe** เป็นเครื่องมือสำหรับผู้พัฒนาและผู้จัดจำหน่าย (Admin/Seller) สำหรับ:
1. ปั๊มและสร้างกุญแจ USB Dongle ลิขสิทธิ์ความปลอดภัยสูง
2. รีเซ็ตรหัสผ่านผู้ดูแลระบบ (Admin) ให้ลูกค้ากรณีลูกค้าลืมรหัสผ่าน

> [!CAUTION]
> **ข้อควรระวังเรื่องความปลอดภัยสูงสุด:**
> - โปรแกรมนี้ทำงานร่วมกับไฟล์ **`private.pem`** (RSA-2048 Private Key) ซึ่งเป็นกุญแจลับดิจิทัลสำหรับลงลายเซ็นต์อิเล็กทรอนิกส์
> - **ห้ามส่งมอบโปรแกรมนี้ หรือแจกจ่ายโฟลเดอร์ Tools/ไฟล์ private.pem ให้กับลูกค้าเด็ดขาด**
> - ให้เก็บรักษาโฟลเดอร์ `HotelPOS_Tools` ไว้เฉพาะในเครื่องของผู้จัดจำหน่ายเท่านั้น

## 2. การเลือก USB Flash Drive เป้าหมาย

1. เสียบ USB Flash Drive ใดก็ได้เข้ากับช่อง USB ของเครื่องคอมพิวเตอร์
2. เปิดโปรแกรม `PSoftRestRentGenerator.exe`
3. ในส่วน **"1. เลือก USB Flash Drive ที่เสียบอยู่"**:
   - กดปุ่ม **[รีเฟรช]** หากยังไม่เห็นรายชื่อไดรฟ์
   - คลิกเลือกแฟลชไดรฟ์เป้าหมายจากรายการ Dropdown
   - โปรแกรมจะแสดงรายละเอียด Serial Number ระดับชิปฮาร์ดแวร์, ชื่อ Volume Label และความจุของไดรฟ์

## 3. การกำหนด App Serial Watermark และประเภทลิขสิทธิ์

ในส่วน **"2. ตั้งค่าคีย์และ App Serial Watermark"**:

1. **App Serial Watermark (รหัสลายน้ำโปรแกรม)**:
   - กำหนดรหัสประจำตัวไคลเอนต์ เช่น `APP-2026-CLIENT-A`
   - หากต้องการเขียนไฟล์ `app.watermark` ลงในโปรแกรมหลัก ให้กดปุ่ม **[เซฟ app.watermark]**
   
2. **ประเภทสิทธิ์ใช้งาน (License Type)**:
   - **Lifetime (ใช้งานถาวร)**: ไม่กำหนดวันหมดอายุ ลูกค้าใช้งานรุ่นเต็มได้ตลอดไป
   - **Standard (รายปี / กำหนดวัน)**: กำหนดวันหมดอายุสิทธิ์ผ่านช่อง *วันหมดอายุสิทธิ์* (เมื่อหมดอายุจะสลับเข้าสู่ Read-Only Mode)
   - **Trial (ทดลองใช้งาน 30 วัน)**: สิทธิ์ทดลองใช้งานชั่วคราว

## 4. การสร้างและอัปเดตคีย์ (Gen Key & Edit Key)

1. **ตัวเลือกการฟอร์แมต (Quick Format Option)**:
   - ติ๊กถูกที่ช่อง **"ฟอร์แมต USB Drive (Quick Format) ก่อนเขียนคีย์ใหม่"** หากต้องการล้างข้อมูลไดรฟ์ให้สะอาดก่อนปั๊มคีย์ (แนะนำระบบไฟล์ `FAT32`)

2. **การสร้างคีย์ใหม่ (Gen Key)**:
   - กดปุ่มสีเขียว **[Gen Key (สร้างคีย์ใหม่ลง USB)]**
   - โปรแกรมจะทำ Quick Format (ถ้าเลือก) ➔ ดึง USB Hardware Serial ➔ ลงลายเซ็น RSA 2048-bit ➔ สร้างไฟล์ `license.key` ที่เข้ารหัสสมบูรณ์ลงใน USB Flash Drive

3. **การอัปเดตคีย์เดิม (Edit Key)**:
   - กดปุ่มสีน้ำเงิน **[แก้ไขคีย์ (อัปเดตคีย์เดิมใน USB)]**
   - ใช้เมื่อต้องการต่ออายุสิทธิ์ หรือเปลี่ยนประเภทสิทธิ์ใน USB ใบเดิมโดยไม่ลบไฟล์อื่นในไดรฟ์

## 5. การทดสอบปลดล็อกและการตรวจสอบคีย์ (Validate & Payload)

1. **ทดสอบปลดล็อก (Validate)**:
   - กดปุ่มสีส้ม **[ทดสอบปลดล็อก (Validate)]**
   - โปรแกรมจะทำการตรวจสอบลายเซ็น RSA และจับคู่ Hardware Serial ของ USB ที่เสียบอยู่ หากถูกต้องจะขึ้นแจ้งเตือน `License Status: Active`

2. **ดูข้อมูลคีย์ JSON Payload**:
   - กดปุ่มสีเทา **[ดูข้อมูลคีย์ JSON Payload]**
   - โปรแกรมจะแสดงโค้ดโครงสร้าง JSON ภายในคีย์ เช่น HardwareId, LicenseType, IssueDate, ExpireDate และ Digital Signature

## 6. การรีเซ็ตรหัสผ่าน Admin สำหรับลูกค้า (Reset Customer Password)

หากลูกค้าลืมรหัสผ่านเข้าใช้งาน หรือลืมรหัสผ่านสำหรับการทำ ZetZero (ล้างระบบ):

1. กดปุ่มสีแดง **[รีเซ็ตรหัสผ่าน Admin ของลูกค้า (Reset Customer Password)]**
2. ในหน้าต่างที่เด้งขึ้นมา:
   - คลิกปุ่ม **[เลือกไฟล์...]** เพื่อเลือกไฟล์ฐานข้อมูล `hotel_pos.db` ของลูกค้า (ปกติจะอยู่ที่ `%APPDATA%\HotelPOS\hotel_pos.db`)
   - ในช่อง **"รหัสผ่าน Admin ใหม่ที่ต้องการตั้ง"**: กรอกรหัสผ่านใหม่ที่ต้องการ (ค่าเริ่มต้นเตรียมไว้ให้เป็น `psoft123`)
3. กดปุ่ม **[ยืนยันรีเซ็ตรหัสผ่าน]**
4. ระบบจะทำการอัปเดตตาราง `SystemSettings` ในฐานข้อมูลของลูกค้าทันที สามารถแจ้งรหัสผ่านใหม่ให้ลูกค้าเข้าใช้งานได้ทันที

## 7. การแก้ไขปัญหาและคำถามที่พบบ่อย (Troubleshooting & FAQ)

- **Q: เปิดโปรแกรมแล้วขึ้นเตือน "ไม่พบไฟล์ Private Key (private.pem)"?**
  - **A:** ตรวจสอบว่าไฟล์ `private.pem` วางอยู่ในโฟลเดอร์เดียวกับโปรแกรม `PSoftRestRentGenerator.exe` แล้วหรือยัง

- **Q: เสียบ USB แล้วโปรแกรมมองไม่เห็นไดรฟ์?**
  - **A:** กดปุ่ม **[รีเฟรช]** หรือถอดแล้วเสียบ USB เข้าพอร์ตใหม่ แล้วลองกดรีเฟรชอีกครั้ง

- **Q: ลูกค้าทำ USB Dongle หาย ต้องทำอย่างไร?**
  - **A:** นำ USB Flash Drive ใบใหม่มาเสียบเข้าเครื่องผู้ขาย ➔ กรอก App Serial Watermark เดิมของลูกค้า ➔ กด **[Gen Key]** เพื่อสร้าง Dongle ทดแทนใบเดิมได้ทันที
