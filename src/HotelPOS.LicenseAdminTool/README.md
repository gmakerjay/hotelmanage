# HotelPOS.LicenseAdminTool

โปรแกรมนี้ใช้ **เฉพาะทีมขาย/แอดมิน** ห้ามแจกให้ลูกค้าเด็ดขาด — จะเขียนใน **Phase 1: Core License**

จะมีฟังก์ชันตาม PROJECT_PLAN.md ข้อ 6.4:
- Gen Key ใหม่ (ผูก Hardware ID ลูกค้า)
- กำหนดจำนวนวัน (7 / 15 / 30 / 90 / 180 / 365 / ถาวร)
- เพิ่ม/ลดวัน, เปลี่ยนแพ็กเกจ, ถอน/ระงับ (Revoke), ล้างข้อมูล License
- ดูประวัติ Key ทั้งหมด, Export/Import ฐานข้อมูล Key

**ข้อกำหนดความปลอดภัย (บังคับ):**
- ต้องมี Login/Password (หรือ 2FA) ของผู้ขายเองก่อนเปิดใช้เครื่องมือนี้
- RSA Private Key เก็บแยกไฟล์ นอก source control (เช่น ใน `%AppData%` ของเครื่องแอดมินเท่านั้น อย่า commit เข้า git)
